Set up the fictional reviewer resume

The first Companion release supports macOS 14.4 or later. A compatible signed macOS installer is not yet available; public stable v2.2.0 does not support this Companion version. Read the Companion reviewer setup guide for prerequisites and the complete test flow. This download contains only the fictional Alex Morgan resume. It is one resume document, not a profile or a full-workspace backup.

Download the fictional resume (JSON)

  1. In On Paper, open Settings → Account → New profile. Name it Companion Review (Fictional) and choose Create & switch. If onboarding appears after switching, use its Cancel control.
  2. In the main window, open Resume actions → Import… (the three dots beside the resume selector) and select companion-reviewer-resume.json. In a narrow window, use Menu → Import. Use this resume import, not Import profile.
  3. Check that the imported resume shows Alex Morgan and alex.morgan@example.com. You may rename it Product Design through Resume actions. Keep all review data fictional.
  4. AI assistance requires your own OpenRouter account, key, and available model, configured directly in Settings → AI. Accept the app’s AI-sharing disclosure when prompted. No reviewer test account is currently available; do not enter a key into this page or the extension.
  5. Return to this page, invoke Companion from Chrome’s toolbar, accept its disclosure, pair with the app, and choose the imported resume. Review before filling; leave work-authorization and EEO questions blank.
First launch: if the welcome wizard blocks the main window

Configure your available OpenRouter key in the wizard, choose Import existing resume, and paste this fictional text into Import your resume. Review the parsed facts, continue to Create resume, and finish onboarding. This parse uses real AI. Then follow the JSON import steps above for the exact fixture. The wizard accepts TXT/PDF/DOCX, not the JSON download.
