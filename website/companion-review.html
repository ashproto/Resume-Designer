Companion reviewer setup

Review On Paper Companion with a fictional resume and application page. The first release supports Chrome 116 or later on macOS 14.4 or later.

Compatible macOS installer is not yet available

End-to-end review requires a signed On Paper for macOS release with Companion support. Its versioned installer link will appear here when that release is available.

The current public stable v2.2.0 does not support this Companion version. The general desktop download is not a substitute. You can inspect the fictional materials now; the complete test flow must wait for the compatible installer and working AI access.

Fictional test materials

  • Open the fictional application — browser preview only; no employer submission or file upload.
  • Download the fictional resume (JSON) — Alex Morgan, with fictional career history and reserved example contact details.

AI features use OpenRouter; provider charges may apply. For Chrome Web Store review, the review-only OpenRouter key is supplied privately in the Dashboard Password field. Enter it only in the desktop app’s Settings → AI and choose Claude Sonnet 4.6, the tested model. No credential is published on this page.

Set up the app and extension

  1. Once the compatible versioned installer above is available, install it and keep one On Paper instance running. Use the extension revision supplied for this review.
  2. Open Settings → Account → New profile, name it Companion Review (Fictional), and choose Create & switch. If onboarding appears after switching, use its Cancel control.
  3. Choose Resume actions → Import… beside the resume selector, or Menu → Import in a narrow window. Select the downloaded JSON. This imports one resume, not a profile or full backup. Check for Alex Morgan and alex.morgan@example.com; optionally rename the resume Product Design.
  4. Copy the review-only OpenRouter key from the Chrome Web Store Dashboard Password field into the desktop app’s Settings → AI. Select Claude Sonnet 4.6 and accept the native AI-sharing disclosure when prompted. Never put a key into this page, the extension, a screenshot, or a public support message.
  5. Open the fictional application in Chrome and invoke Companion from the toolbar on that tab. Read Before you connect, then choose Agree and continue.
  6. Choose Open and connect and approve the request in On Paper. Confirm Connected. If pairing does not complete, choose Cancel and pair manually, or open Pair manually. Copy the token from Settings → Data → Companion extension in On Paper, paste it only into the extension, and choose Pair with token.

If a first-launch welcome wizard blocks the main window, use the fictional first-launch text and instructions in the demo page’s setup section. The wizard parses TXT/PDF/DOCX or pasted text using AI; import the JSON through Resume actions afterward.

Review the main flow

  1. Select the fictional resume and choose Prepare autofill review. Review all nine fields. Work authorization and EEO gender should stay manual. Edit a supported answer before filling.
  2. Choose Fill reviewed fields. Check the supported values and visible PDF filename on the page. Confirm availability if the model leaves it unanswered. With six ordinary answers and the PDF present, Preview demo application reports 7 of 9 fields completed; the two sensitive controls remain blank.
  3. Open Tailor resume and choose Analyze fit. Check that an explanation appears; scores and wording vary. Choose Create tailored resume and confirm a separate resume copy is created and selected, with a fresh review and no automatic fill. Real AI operations can take about a minute.
  4. If an unanswered editable, non-sensitive field offers Save answer after you enter a fictional value, save it and confirm Answer saved. Skip this check if every supported field already has a suggestion. Separately choose Log application and check the fictional record in On Paper.
  5. Choose Disconnect while On Paper is running. Confirm browser access is cleared and app access revoked. Reconnect to continue. Quit the app to check recovery, then open it again and choose Check connection again.

Data and test boundaries

Use only the fictional materials. The demo page keeps form values and the selected PDF in the tab and cancels form submission. Requesting Companion assistance still sends the disclosed resume/profile, supported field, and job context through On Paper to OpenRouter and the selected or fallback model provider. Workspace records may sync through your own iCloud account.

Companion never activates a site’s final Submit control. On real application sites, filling may trigger the site’s autosave or file upload. Some custom controls and recognized sensitive questions require manual entry. Read the privacy policy before using AI or personal information.
